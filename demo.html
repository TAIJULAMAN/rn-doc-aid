🏥 Doc Aid

Doctor Appointment & Telehealth App

📱 About the App

Doc Aid is a complete React Native Expo application built with TypeScript, featuring a clean medical aesthetic and intuitive booking flow for doctor appointments and telehealth consultations.

The app includes animated onboarding, doctor discovery, real-time availability checking, and a sophisticated time slot booking system with automatic past slot disabling.

✨ Key Features

🎯

Onboarding Flow

Beautiful animated slides introducing key features with smooth transitions and pagination dots.

🏠

Home Dashboard

Search bar, specialty categories, and top doctors listing with ratings and availability.

📅

Smart Booking

Calendar strip, time slot grid (Morning/Afternoon/Evening), and automatic past slot disabling.

👨‍⚕️

Doctor Profiles

Comprehensive profiles with stats, reviews, experience, and patient testimonials.

💳

Payment Options

Choose between Pay at Clinic or Pay Online with clear fee display.

🚀 Run the App

To run the Doc Aid app on your device or simulator:

cd c:\Projects\rn-doctor-appointment-app && npx expo start

Then press 'i' for iOS simulator or 'a' for Android emulator

📁 Project Structure

The codebase follows a feature-based architecture:

  • src/components/ - Shared UI components (Button, Card, DoctorCard)
  • src/features/ - Feature modules (auth, home, doctors, booking)
  • src/navigation/ - App navigation setup
  • src/types/ - TypeScript interfaces
  • src/theme/ - Design system (colors, typography, shadows)
  • src/utils/ - Helper functions (time slot generation, availability checking)

🎯 Core Booking Logic

The app implements sophisticated time slot management:

  • generateTimeSlots() - Creates slots from doctor availability
  • categorizeTimeSlots() - Groups by Morning/Afternoon/Evening
  • Automatic disabling - Past slots are disabled if date is today
  • Real-time checking - Availability updates based on current time
